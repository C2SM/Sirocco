# Plugins

Tasks behavior is implemented in so-called task plugins. Two of them are currently avilable, namely `shell` and `icon`. The former can be considered as an _all rounder_ task where users bring their own set of files (typically scripts) and the later, as the name indicates, is specifically designed as an interface to the ICON model.

Specifications corresponding or a particular plugin are listed at the same level as [the ones applying to any task](../../configuration/tasks) like `plugin` itself.
